# Udemy Clone Website

This is a Udemy clone website built using **HTML and CSS Flexbox**.  
It is a front-end practice project to improve layout design and responsive UI skills.

## Website Sections

- Navbar  
- Categories Section  
- Course Recommendation Section  
- Popular Courses Section  
- Footer End Section  

## Features

- Flexbox-based layout  
- Clean and modern UI  
- Static course cards design  
- Beginner-friendly front-end project  

## Technologies Used

- HTML5  
- CSS3 (Flexbox)
